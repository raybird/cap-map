# 國中社會科時空事件擴充設計

日期：2026-05-21

## 背景

目前 `cap-map` 的事件資料主要集中在臺灣史，事件總數為 34 筆，能支撐基本的時間軸與地圖互動，但距離國中社會科課程主幹仍有明顯缺口。尤其中國史與世界史幾乎尚未納入，導致產品雖然已有時空地圖形式，卻還不能完整對應國中社會科的重要學習內容。

本次擴充目標不是把所有課本名詞都轉成事件，而是優先補齊「最適合時空地圖」的課程內容：必須同時具有明確時間與地點，並能支援地圖判讀、時序比較與因果理解。

## 目標

1. 把事件資料從以臺灣史為主，擴充成可覆蓋國中社會科歷史主幹的事件庫。
2. 維持產品的核心定位：事件需要能自然呈現在地圖與時間軸上。
3. 不修改現有 UI 與資料核心結構，優先用最低風險方式完成課程內容擴充。
4. 優先補齊歷史內容，再視後續需要考慮是否延伸至更適合事件化的地理或公民內容。

## 非目標

1. 本階段不重新設計地圖介面、側欄或搜尋功能。
2. 本階段不新增複雜的新資料欄位。
3. 本階段不嘗試把所有公民概念硬轉成事件。
4. 本階段不追求課本所有細節完整收錄，而是先建立一套可持續擴充的主幹事件庫。

## 現況摘要

現有事件資料位於 `webapp/public/assets/data/events.json`，時間軸位於 `webapp/public/assets/data/timeline.json`。

目前共有 34 筆事件，時期分布如下：

- `prehistory`: 3
- `dutch-spanish`: 3
- `zhengshi`: 2
- `qing-rule`: 8
- `japanese-rule`: 8
- `postwar`: 5
- `democratization`: 3
- `modern`: 2

目前資料優勢在於臺灣史已有初步骨架，且事件格式已包含標題、描述、日期、地點、分類、關鍵字、關聯事件與會考相關度欄位，因此適合直接沿用並擴充。

## 擴充策略

本次採用「歷史主線擴充型」，並參考會考高頻考點排序資料優先度。

策略原則如下：

1. 先補齊中國史與世界史的主幹內容，填補目前最大課程缺口。
2. 臺灣史保留較細粒度，維持既有優勢。
3. 中國史與世界史多以章節級重要事件為主，避免資料量膨脹過快。
4. 只有當事件拆細後仍明顯有助於地圖與時序理解時，才採用較細粒度。

## 事件選擇規則

### 一定收錄

符合以下條件的事件，優先納入：

1. 有明確時間點或可接受的時間區間。
2. 有主要發生地、政權中心、戰場、港口、城市或文明區域可對應。
3. 屬於國中社會科歷史主幹內容。
4. 適合支援地圖判讀、時序比較、因果理解或跨區域互動。

### 優先細拆

以下情況可以採較細粒度：

1. 臺灣史高頻事件。
2. 會考常見圖表題、時序題、因果題素材。
3. 主題拆開後，仍能各自對應獨立時間與地點。

例：`甲午戰爭`、`馬關條約`、`臺灣民主國` 可分別作為獨立事件。

### 維持章節級

以下事件保留為較大節點：

1. 雖有地點，但拆太細後對學習幫助有限。
2. 主要價值在理解一段時代變化，而非單一日子的事件。

例：`文藝復興`、`工業革命`、`冷戰格局形成`。

### 暫不納入

以下內容先不納入：

1. 沒有合理地點可定位。
2. 主要是抽象概念、制度名詞或公民原則。
3. 勉強事件化後會削弱地圖產品的定位。

## 資料結構規則

本階段不修改既有 JSON 核心欄位，沿用以下格式：

- `id`
- `title`
- `description`
- `date`
- `location`
- `categories`
- `keywords`
- `relatedEvents`
- `examRelevance`

### categories

`categories` 維持使用現有課程面向，例如：

- `歷史`
- `地理`
- `公民`

本階段不把 `中國史`、`世界史`、`臺灣史` 另外做成分類值，以免影響現有分類行為與 UI 預期。這些資訊改由 `keywords` 與 `textbookReferences` 表達。

### title

採用國中課本常見名稱，避免過度學術化或不同版本名稱差異太大。

### description

控制在 1 至 2 句，以會考導向、容易理解的敘述為主，不追求百科式完整介紹。

### location

優先選主要代表地點，不追求涵蓋所有發生地。若事件本身橫跨大範圍，可接受以文明核心區、首都、戰場或象徵性城市作為代表定位。

### keywords

同時放入：

1. 課本關鍵詞
2. 常見檢索詞
3. 對應題型可能出現的歷史名詞

### relatedEvents

優先連結前後時序事件、因果關係事件與同單元重要事件，讓側欄與未來延伸功能能利用既有關聯資料。

### examRelevance

`importance` 維持使用 `high` 或 `medium`。

`questionTypes` 優先使用現有集合，例如：

- `圖表判讀`
- `概念解釋`
- `因果分析`
- `價值辨析`

## textbookReferences 規則

後續新增事件時，`examRelevance.textbookReferences` 統一採用一致格式，例如：

- `社會科七年級上冊 臺灣史`
- `社會科七年級下冊 臺灣史`
- `社會科八年級上冊 中國史`
- `社會科八年級下冊 世界史`

本階段優先求一致，不先強制加入章次。若未來要做更細課程篩選，再補章節資訊。

## 分批執行方式

建議依下列順序執行：

1. 先補中國史主幹約 12 至 15 筆。
2. 再補世界史主幹約 15 至 20 筆。
3. 最後補臺灣史缺漏約 10 至 12 筆。
4. 每一批新增後，同步補足 `relatedEvents` 關聯。
5. 全部完成後，再檢查 timeline 分期是否足以支撐新增事件的視覺辨識。

## 風險與後續注意事項

1. 世界史與中國史部分事件的地點是文明區域或多地互動，定位必須接受代表性地點，而非絕對精準單點。
2. 現有 timeline 分期偏臺灣史觀點；若未來中國史與世界史事件數量大幅增加，可能需要再討論更通用的時代分組方式。
3. 若未來要納入更多地理或公民內容，應另外定義哪些主題適合事件化，避免把抽象概念直接塞入事件模型。

## 成功標準

本階段完成後，應達成以下結果：

1. 事件庫不再僅限臺灣史，能初步覆蓋國中社會科歷史主幹。
2. 新增事件仍符合地圖產品定位，沒有大量不適合定位的資料。
3. 資料格式維持一致，未破壞現有 UI 與邏輯。
4. 後續可以直接依本設計分批實作與驗證。
